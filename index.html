Add the calendar to your phone or laptop

Save a copy: use the download button to save the events displayed by this page’s current data source as an .ics calendar file. Open or import that file in a compatible calendar application. Search filters do not limit this full download. Downloaded copies do not receive future changes.

Google Calendar: use “Add to Google Calendar” and confirm the school calendar subscription. Google Calendar file imports are done on a computer; subscribed calendars can also be displayed in the phone app.

Apple Calendar or Outlook: subscribe to the school calendar using its feed address, or import the .ics file as a one-time copy. Subscriptions may take time to refresh. If the school’s Google Calendar is sharing availability only, the subscription may show “Busy” until event details are made available.

Subscribe in Apple Calendar

Downloading a document-based event does not create or edit an event in the school’s master calendar.

Please note

Event dates, times, locations and arrangements are subject to change. Any updates will be communicated through official Nün Academy channels. Please check the latest school communications before attending an event or making arrangements.
